# Banking Customer 360 & AI Intelligence Platform

An enterprise-style banking data and AI platform demonstrating
modern Azure lakehouse architecture, batch and streaming data
engineering, data quality, governance and GenAI capabilities.

## Technology Stack

- Python
- PySpark
- SQL
- Delta Lake
- Azure Databricks
- Azure Data Lake Storage Gen2
- Azure Data Factory
- Azure Event Hubs
- Unity Catalog
- Azure AI / GenAI

## Architecture

The platform follows a modern lakehouse architecture:

Sources
→ Data Factory / Event Hubs
→ ADLS Gen2
→ Databricks
→ Bronze
→ Silver
→ Gold
→ AI / Analytics

## Project Goals

1. Demonstrate PySpark data engineering
2. Implement Delta Lake medallion architecture
3. Build batch data pipelines
4. Build real-time streaming pipelines
5. Implement dimensional data modeling
6. Implement data quality controls
7. Demonstrate governance and security
8. Build a GenAI assistant over trusted banking data
